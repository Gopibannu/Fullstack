# Cyber Awareness Web Project

## 📌 Overview

This project is a complete **Login → Signup → Dashboard workflow** built for indepth internal understandings. I learned how real authentication works using **Node.js, Express, MySQL**, and how to manage my entire project using **Git & GitHub**.

---

# 📘 What I Learned

## ✅ 1. **Backend Development (Node.js + Express)**

* Creating routes (`POST /signup`, `POST /login`, `GET /dashboard`)
* Using Express middleware
* Sending JSON responses and handling request bodies
* Using `async/await` for smooth API calls

## ✅ 2. **Database (MySQL Workbench)**

* Creating database and tables
* Designing proper schema for authentication
* Testing queries
* Understanding `SELECT`, `INSERT`, and `WHERE` conditions
* Understanding why we use `result[0]`

## ✅ 3. **Frontend + Backend Communication**

* Using `fetch()` to send data to backend
* Using `await` to wait for response
* Understanding how request → response cycle works
* Displaying user data on dashboard

## ✅ 4. **Git & GitHub Version Control**

I learned how to initialize, commit, push, and manage my project using Git.

---

# 🧾 All Git Commands I Used

Below is the full list of Git commands used in order.

### 🔹 **Initialize Git**

```
git init
```

### 🔹 **Check Git Status**

```
git status
```

### 🔹 **Set Identity**

```
git config --global user.name "Gopi Chandu"
git config --global user.email "your-email@example.com"
```

### 🔹 **Stage Files**

```
git add .
```

### 🔹 **Commit Files**

```
git commit -m "Initial commit"
```

### 🔹 **Add GitHub Remote Origin**

```
git remote add origin https://github.com/YOUR-USERNAME/cyber-awareness-project.git
```

### 🔹 **Rename Branch to Main**

```
git branch -M main
```

### 🔹 **Push Code to GitHub**

```
git push -u origin main
```

### 🔹 **For Future Updates**

```
git add .
git commit -m "Update message"
git push
```
